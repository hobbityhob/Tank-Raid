# Tank Raid

A cooperative 1–2 player tank game built with the kids in the Kids Games project.

## Play

Open `index.html` in a browser, or deploy the repository as a static site (for example with Netlify).

### Controls

- Player 1: **WASD** to move/steer, **Space** to fire
- Player 2: **Arrow keys** to move/steer, **Enter** to fire
- **Esc** opens the game menu
- Tablet mode provides on-screen controls

## Current features

- 50 levels in 5 sections
- A boss on level 5 of each section and a super boss on level 10
- Final level with two bosses and a vault objective
- 1-player and always-split-screen 2-player modes
- Normal 3-life mode and 1-Life Challenge mode
- Revive pickups in 2-player games
- Destructible crates with temporary weapon, health, and money drops
- Permanent weapons purchased in the garage
- Ordinary gun, laser, ultra 3-cannon, guided missile, spread shot, mine layer, and Hyper Laser
- Minimap
- Big Screen mode
- Tablet controls
- Named save codes and level select
- Five battlefield color themes with textured ground, walls, crates, and tanks

Everything is contained in `index.html`; there is no build step or external dependency.
